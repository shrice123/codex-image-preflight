Codex 图片压缩 · Windows 便携版

适用于 64 位 Windows 上的 Codex 桌面客户端。无需安装 Python。

1. 将 ZIP 完整解压到本地，再双击 Codex Image Prep.exe。
2. 看到“自动压缩已启动”后，点确定，照常使用 Codex。
3. 截图或复制图片后在 Codex 输入框按 Ctrl+V。也可以从 Windows 资源管理器直接拖入普通本地图片文件。
4. 等附件缩略图出现，再按平常方式发送消息。需要停止时，再次双击同一个 EXE，并确认停止。

每张图片文件最多 99,999 字节。每次粘贴或拖放算一批，图片按 Base64 长度加附件开销估算，整批最多 200,000 字节。同一条消息分几次加图时，各批分别计算。正文和历史上下文也会占用完整请求的空间。

程序在本机压缩，原图保留。输出写入 Windows 临时目录。程序只在当前 Windows 登录期间运行，重启后需要再次双击启动。网页端、右键粘贴和 Codex 的附件选择器不在自动处理范围内。
