Codex 图片压缩 · Windows 便携版

适用于 64 位 Windows 上的 Codex 桌面客户端。无需安装 Python。

1. 下载 EXE 后直接双击。若下载的是 ZIP，先完整解压，再双击 Codex-Image-Prep-Windows-x64.exe。
2. 看到“自动压缩已启动”后，点确定，照常使用 Codex。
3. 在 Codex 中按 Ctrl+V 粘贴图片，从资源管理器拖入图片，或通过「＋ → 文件和文件夹」选取本地图片。
4. 等附件缩略图出现，再按平常方式发送消息。需要停止时，再次双击同一个 EXE，并确认停止。

每张图片文件最多 99,999 字节。每次粘贴、拖放或确认文件选择算一批，图片按 Base64 长度加附件开销估算，整批最多 200,000 字节。混选的普通文件使用原路径。同一条消息分几次加图时，各批分别计算。正文和历史上下文也会占用完整请求的空间。

程序在本机压缩，原图保留。输出写入 Windows 临时目录。程序只在当前 Windows 登录期间运行，重启后需要再次双击启动。网页端和右键粘贴按原有方式工作。

独立 EXE 支持 JPEG、PNG、WebP、GIF、BMP 和 TIFF 等常用格式。AVIF 可使用源码版处理。
